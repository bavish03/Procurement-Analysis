## Procurement & Supply Chain Analytics Dashboard

## Project Overview

This project presents an end-to-end Procurement & Supply Chain Analytics solution developed using the DataCo Supply Chain Dataset. The objective was to transform raw transactional data into meaningful business insights through data cleaning, SQL analysis, and interactive Power BI visualizations.
The dashboard enables procurement professionals to monitor procurement spending, delivery performance, shipping efficiency, and category-wise purchasing trends to support data-driven decision-making.

## Dataset Information

Dataset: DataCo Supply Chain Dataset
Total Records: 180,520
Total Columns: 54
The dataset contains procurement, customer, product, order, shipping, and delivery information for supply chain analysis.

## Business Objectives

- Analyze overall procurement spending.
- Monitor order volume and purchase quantity.
- Evaluate delivery performance.
- Identify high-spending product categories.
- Compare procurement performance across different markets.
- Analyze shipping modes and logistics efficiency.
- Build an interactive executive dashboard.

Data cleaning and transformation were performed using Power Query due to the large dataset size.
The following steps were completed:

- Verified data types

- Removed unnecessary fields
- Checked for missing values
- Created a Date Dimension table
- Built relationships for reporting

## Business Insights

- Europe recorded the highest procurement expenditure among all markets.
- Standard Class was the most frequently used shipping mode.
- A small number of product categories contributed a significant portion of procurement spending.
- Delivery performance analysis highlighted opportunities to reduce delayed shipments.
- Interactive filtering enables procurement managers to analyze performance by market, year, category, and shipping mode.
